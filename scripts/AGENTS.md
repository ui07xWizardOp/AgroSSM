# scripts/AGENTS.md — Scripts Directory

## Purpose
This directory contains CLI entrypoint scripts to train, evaluate, and inspect the AgroSSM model.

## Scripts
- `train_model.py` — Train script for self-supervised pretraining (Phase 3.1) and supervised fine-tuning (Phase 3.2).
- `evaluate_model.py` — Evaluation script calculating metrics, bootstraps, and OOD performance.
