# config/AGENTS.md — Configuration Directory

## Purpose
This directory contains YAML configuration files that control the data processing, model hyperparameters, and self-supervised pretraining schedules.

## Files
- [data_config.yaml](file:///c:/Users/KIIT0001/Downloads/AgroFM/config/data_config.yaml) — Configures the US Corn Belt (Iowa/Illinois) maize region, composite lengths, data sources, and blocked splits.
- [model_config.yaml](file:///c:/Users/KIIT0001/Downloads/AgroFM/config/model_config.yaml) — Configures tokenizer embedding sizes, SSM/SWA/MLA blocks depth and parameter configurations, Mixture of Experts (MoE) routing, supervised task heads, training learning rates, and physics lambdas.
- [ssl_config.yaml](file:///c:/Users/KIIT0001/Downloads/AgroFM/config/ssl_config.yaml) — Placeholder for self-supervised training targets and schedule overrides.
