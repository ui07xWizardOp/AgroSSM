AgroEarthFM-MVP Architecture

Clean vertical view — multi-resolution inputs, encoders, fusion, temporal memory, task heads, and validation controls

MAIN MODEL PIPELINE
1. Multi-Resolution Inputs

EO / Vegetation

  • HLS, Sentinel‑2, Landsat
  • NDVI, EVI, NDWI
  • Native 10–30 m

Weather / Climate

  • Rainfall, temperature
  • Humidity, radiation, wind
  • Native coarse scale

Soil / Hydro

  • SoilGrids, SMAP/CCI
  • Water capacity, texture
  • Uncertainty retained

Crop Context

  • Crop type and calendar
  • Planting window
  • Crop-mask confidence

Validation Labels

  • Phenology / stress / yield
  • Drought-event records
  • Validate at label scale
↓

2. Quality-Controlled Multi-Resolution Datacube

  • No forced 10 m upscaling of coarse climate/soil variables
  • Native scale metadata, cloud/gap/crop masks, modality masks, and no-leakage train/validation/test splits are retained
↓
3. Modality-Specific Encoders

EO Temporal Encoder

  • Compact ViT / CNN‑ViT
  • Spectral + temporal tokens

Weather Encoder

  • Transformer / TCN
  • Lag-aware forcing

Soil / Static Encoder

  • MLP or shared GNN
  • Soil/hydro tokens

Crop Calendar Encoder

  • Crop prior
  • Explicit AGDD accumulator

Missing-Modality Handler

  • Learned null tokens, modality-present masks, and modality dropout during training
↓
4. Fusion and Temporal Memory

Scale-Aware Ordered Fusion

  • Cross-resolution attention or gated fusion
  • Process bias: weather → soil/water → vegetation → phenology

Hierarchical Temporal Memory

  • Fine 5–10 day dynamics
  • Coarse monthly/seasonal context
  • Stress accumulation and recovery memory
↓

5. Shared Agro-Ecosystem State zt

  • Encodes vegetation health, soil-water state, phenology state, stress accumulation, latent residual-water anomaly, and uncertainty
↓
6. Output Heads

Crop Stress

  • Water/heat stress
  • Probability + uncertainty

Phenology Forecast

  • Stage prediction
  • Transition timing

Drought Trajectory

  • Onset/intensity
  • Recovery forecast

Yield-Risk / Anomaly

  • Production risk only
  • Not food-security risk

Residual Water + Uncertainty

  • Unobserved water input
  • Not automatically irrigation
TRAINING AND VALIDATION CONTROLS

A. Process-Centered SSL

  • Masked spatiotemporal reconstruction
  • Cross-modal masked prediction
  • Future vegetation trajectory
  • Phenology and drought trajectory objectives

B. Weak Physics Regularisation

  • ΔSM = P + Ilatent − ET − R − D + ε
  • AGDD + water + radiation growth limits
  • Accepted only if consistency improves without task collapse

C. Temporal-DAG Diagnostics

  • No same-time causal cycles
  • CropStaget → Vegetationt
  • Vegetationt → CropStaget+1
  • Sign, monotonicity and invariance checks

D. Baselines and Gates

  • Climatology, persistence, GDD, SPI/SPEI/VHI
  • RF/XGBoost, LSTM/TCN
  • Single-modality and no-physics ablations
  • G0–G7 go/no-go gates
