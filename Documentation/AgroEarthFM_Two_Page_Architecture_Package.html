A. MAIN INFERENCE PIPELINE
1. Multi-Resolution Inputs

EO / Vegetation

  • HLS, Sentinel‑2, Landsat
  • Optional SAR fallback
  • NDVI, EVI, NDWI, LAI/FAPAR if available
  • Native: 10–30 m

Weather / Climate

  • Rainfall, temperature
  • Humidity, radiation, wind
  • VPD / ET drivers
  • Native coarse scale retained

Soil / Hydro

  • SoilGrids, SMAP/CCI
  • Water capacity, soil texture
  • DEM/topography optional
  • Uncertainty retained

Crop Context

  • Crop type, crop calendar
  • Planting window
  • Crop-mask confidence
  • Irrigation proxy if known

Validation Labels

  • Phenology/stress/yield labels
  • Drought-event records
  • Administrative yield if field labels absent
  • Validated only at label scale
↓

2. Quality-Controlled Multi-Resolution Datacube

  • No forced 10 m upscaling: coarse climate, soil moisture, and groundwater signals remain scale-aware.
  • Stores CRS/time metadata, native scale, cloud/gap masks, crop-mask confidence, modality-present masks, data-quality flags, and locked no-leakage train/validation/test splits.
↓
3. Modality-Specific Encoders

EO Temporal Encoder

  • Compact ViT / CNN‑ViT
  • Spectral + temporal patch tokens
  • Vegetation trajectory features

Weather Temporal Encoder

  • Transformer / TCN / GRU-hybrid
  • Lag-aware climate forcing
  • Heat/rainfall stress patterns

Soil / Static Encoder

  • MLP or optional shared GNN
  • Soil and hydro-context tokens
  • No duplicate topology GNN

Crop Calendar Encoder

  • Crop type and phenology prior
  • Planting-window features
  • Explicit AGDD accumulator

Missing-Modality Handler

Learned null tokens + modality-present masks + modality dropout, so the model degrades gracefully when irrigation, SAR, groundwater, or soil moisture is unavailable.

↓
4. Fusion and Temporal Memory

Scale-Aware Ordered Fusion

  • Cross-resolution attention or gated fusion
  • Process-informed order: weather → soil/water → vegetation → phenology
  • Token budget controlled to avoid transformer blow-up

Hierarchical Temporal Memory

  • Fine path: 5–10 day vegetation/stress dynamics
  • Coarse path: monthly/seasonal climate context
  • Tracks lagged drought, recovery, AGDD, and stress accumulation
↓

5. Shared Agro‑Ecosystem State zt

Encodes vegetation health, soil-water state, phenology state, water/heat stress accumulation, latent residual-water anomaly, and predictive uncertainty.

↓
6. Output Heads

Crop Stress

  • Water/heat stress score
  • Event probability
  • Uncertainty

Phenology Forecast

  • Current stage
  • Next transition timing
  • Transition probability

Drought Trajectory

  • Onset, intensity, recovery
  • Lead-time forecast
  • Stress evolution

Yield‑Risk / Anomaly

  • Yield anomaly
  • Below-threshold risk
  • Production risk only

Residual Water + Uncertainty

  • Latent unobserved water input
  • Not automatically irrigation
  • Error/confounder signal

B. TRAINING OBJECTIVES AND LOSS DESIGN

Sequential Process-Centered SSL

  • SSL‑1: masked spatiotemporal reconstruction
  • SSL‑2: cross-modal masked prediction
  • SSL‑3: future vegetation trajectory prediction
  • SSL‑4: phenology pseudo-transition prediction
  • SSL‑5: drought stress trajectory prediction
  • Scenario augmentation only after physics validation

Stability Monitoring

  • Embedding variance and rank
  • Collapse diagnostics
  • Gradient norms and gradient conflicts
  • Linear-probe tracking
  • Objective-level ablation before full multi-task training
Ltotal = Σ αiLSSL_i + λwater(t)Lwater + λgrowth(t)Lgrowth + λDAG(t)LDAG + λcalibLcalib
Training rule: start with representation learning, then add process objectives, then weak physics, and only then temporal-DAG diagnostics. Do not activate all losses at full strength from the beginning.
C. PHYSICS AND CAUSAL-INFORMED STRUCTURE

Weak Water-Balance Regularisation

ΔSM = P + Ilatent − ET − R − D + ε
  • Ilatent represents unobserved water input, possible irrigation, groundwater, or residual mismatch.
  • Residuals must not be automatically interpreted as irrigation without external validation.

Plant-Growth Constraint

  • Uses AGDD, water availability, radiation, and crop-stage-specific stress sensitivity.
  • AGDD is explicitly accumulated from planting date: AGDDt = Σ max(0, Tmean − Tbase).

Temporal-DAG Correction

  • No same-time bidirectional causal cycles.
  • CropStaget → VegetationHealtht
  • VegetationHealtht → CropStaget+1
  • VegetationHealtht, CropStaget, Stresst → YieldRiskt+1

F. BASELINES AND ABLATIONS

Required Baselines

  • Climatology and persistence
  • GDD phenology model
  • SPI/SPEI/VHI drought models
  • RF/XGBoost and LSTM/TCN
  • Satellite-only, weather-only, soil-only
  • Existing GeoFM features if feasible

Required Ablations

  • No physics
  • No process SSL
  • No crop calendar
  • No weather/soil context
  • No missing-modality training

H. NON-NEGOTIABLE ANTI-FAILURE RULES

No False Precision

Coarse weather/soil products may guide predictions but must not be interpreted as true 10 m observations.

No Temporal Leakage

Forecasting tasks cannot use future EO, future weather, full-season composites, or target-year labels.

No Overclaiming

Outputs are agricultural production risk, not direct food-security risk, unless socioeconomic layers are added.

No Unsupported Causality

Scenario outputs are not decision-grade causal counterfactuals unless externally validated.
